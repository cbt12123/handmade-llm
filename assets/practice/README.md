## 怎样做练习

1. 先写预测或判断，包含中间计算与理由。
2. 卡住时看提示，回正文对应小节；让AI解释卡住的一个步骤，不直接索取整题答案。
3. 运行一个最小例子核对预测，再阅读参考答案，记录不一致的原因。
4. 第二部分以后，按章节已有运行入口生成自己的报告，再对照本页验收证据。

参考答案可能给一种写法；方法不同但满足输入约定与检查条件也可以。数值计算允许合理舍入，实际代码容差以正文和参考实现为准。模型成绩、延迟和加速比不要求复制作者数字；要保留失败并解释，不能反复更换测试集挑结果。

## 如何判断是否可以继续

| 层次 | 应提供的证据 | 不能替代它的东西 |
|---|---|---|
| 理解概念 | 自己的计算、符号解释或反例 | 复述术语、直接复制答案 |
| 运行与结果 | 本机输入、命令、输出、正确性检查 | 截图显示“程序结束”、复制作者JSON |
| 实际任务 | 独立评价、错误分析、真实调用或端到端对照 | 训练集成绩、模型自称成功、单算子微基准 |

卡在概念层时先补读，不要求启动后面全部环境。设备不足可以完成手算与报告分析，但标记未实测。模型或算子未达到目标，若能提交真实失败、定位依据和清楚的限制，也完成了相应的分析练习；不能据此宣称应用能力达标。

## 一个可复用的记录模板

第一部分无需交项目报告；后续每章可在自己的笔记中使用下面结构。验收以可复核证据为准。

```text
章节与任务：
我的预测或目标：
输入、数据划分、形状及种子：
环境、配置与运行命令：
生成文件位置：
关键检查及实际结果：
一条错误或边界案例：
与参考结果不同的原因：
当前结论、适用范围与未完成项：
下一步只改变什么、如何再验证：
```

手算、代码执行与作者侧核对都有价值，但并不等于已经由零基础读者验证题目难度。下一轮读者试读应记录卡住的位置、所需提示和耗时，再据此调整。
