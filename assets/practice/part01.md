## 第01章参考答案

A：`values` 为 `[9,4,6]`，求和为10。普通赋值共享同一列表；本例用 `alias=values.copy()` 建立浅副本即可，列表元素都是数字。

B：

```python
def passed_count(scores):
    count = 0
    for score in scores:
        if score >= 60:
            count += 1
    return count

assert passed_count([0, 59, 60, 100]) == 2
assert passed_count([]) == 0
```

常见错误：在循环内提前 `return`，只检查第一项；把 `print(count)` 当成返回值。

## 第03章参考答案

A：形状 `(3,2)`；每科均值 `[50,80]`，每人均值 `[70,95,30]`。`axis=0` 汇总三个人，保留两科；`axis=1` 汇总两科，保留三个人。

B：形状分别 `(3,)` 与 `(3,1)`，相加得到 `(3,3)`，各行为 `[2,3,4]`、`[3,4,5]`、`[4,5,6]`。统一成 `(3,)` 可用 `column.ravel()`；统一成 `(3,1)` 可用 `vector.reshape(-1,1)`。

常见错误：代码能广播就认为数据含义正确；绘图前没有检查数组形状。
