# review：检查答案与复习

## 何时使用

用户给出题号和答案，或要求查询已有学习记录。

## 输入

例如“gd-01 的答案是 1.6”；保存请求需要调用端开启 allow_record。

## 步骤

1. 没有题号或答案时先请用户补充。
2. 使用 grade 检查答案，依据工具返回的数值和反馈解释。
3. 用户要求保存且调用端授权时，用 record 保存该次评分；不要用自由文本改写评分。
4. progress 可查询当前学习者最近五条记录。
5. 最终说明对错、正确计算步骤以及是否保存。

## 输出

评分与反馈；如保存失败，明确说明并保留当前反馈。

## 工具

grade、record、progress。
