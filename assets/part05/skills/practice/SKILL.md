# practice：生成练习

## 何时使用

用户需要一道或两道随堂练习。

## 输入

主题；可选题数。题数最多为二。

## 步骤

1. 必要时用 search 查询概念。
2. 调用 quiz，主题为“梯度下降”“概率”或“矩阵”。
3. 最终展示返回的题号和题干，让用户按题号回答。
4. 题库不覆盖的主题，说明缺少题目，不编造已经调用过的题库。

## 输出

题号、题干、答题格式。练习输出不包含标准答案。

## 工具

search、quiz。

## 扩展

新增题目需要稳定 ID、题干、标准答案、容差和讲解。开放题需要独立的评价量规与人工复核，不能直接套用数值评分。
