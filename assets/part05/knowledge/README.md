# 知识资料的来源

默认索引第一至第四部分的章节正文，不索引 outputs、规则或技能文件。

index_course.py 依据段落边界分块，给出章节相对路径、标题、原始行号和稳定内容 ID。索引保存在 outputs/part05/course_index.json；章节修改后需要重建，工具发现源文件哈希变化时拒绝使用旧索引。

根目录中的教程正文是原始知识来源，本目录存放题库和来源约定，避免复制一份教程后难以同步。

关键词检索默认离线。semantic_search.py 支持用户已经拥有的本地 Sentence Transformers 嵌入模型，运行时不自动下载。两种索引必须分别重建，向量不应跨模型直接混用。
