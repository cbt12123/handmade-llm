# 知识资料的来源

默认索引六个部分的35章与4份学习附录，不索引 README、outputs、规则或技能附件。知识范围扩展不等于题库自动扩展。

index_course.py 在标题内组合邻段，目标700字符、短邻段重叠200字符；数学围栏和 text 流程图完整保留，可执行代码围栏排除。索引给出相对路径、标题、起止行、逐段行范围和内容 ID。源文件集合、哈希或索引格式版本变化时需重建，向量扩展也需重新编码。

根目录中的教程正文是原始知识来源，本目录存放题库和来源约定，避免复制一份教程后难以同步。

关键词检索默认离线。semantic_search.py 支持用户已经拥有的本地 Sentence Transformers 嵌入模型，运行时不自动下载。两种索引必须分别重建，向量不应跨模型直接混用。
