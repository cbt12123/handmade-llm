## 使用方法

进入本部分前，先做[学习路线中的第二部分入口自测](../附录/02-学习路线与前置自测.md#3-第二部分入口数组与函数是否熟悉)。它只检查 Python 与数组，不要求提前学过微积分。读公式时可按需查[数学符号与计算速查](../附录/04-数学符号与计算速查.md)。

- 继续使用 **conda base + VS Code**，只依赖 NumPy、Matplotlib 与 Python 标准库，无需安装新库。
- 各章正文中的 Python 代码块可分别运行；示例中的断言用于核对数学性质和边界。
- 数学公式先看符号对应的具体数值，再手算一个例子，最后运行实验。
- “选修”小节可以暂缓，不阻碍进入后面的机器学习基础。
- 章末产出有任务、参考脚本和验收要求，输出保存在根目录 `outputs/part02/`。

在 VS Code 终端中，先进入项目根目录，再执行参考脚本：

```powershell
conda activate base
python script/part02/04_calculus.py
python script/part02/05_linear_algebra.py
python script/part02/06_probability.py
python script/part02/07_discrete.py
```

代码运行成功是第一步；还要能解释输出变化的原因。公式显示依赖 Markdown 预览支持，若公式渲染不完整，可以对照旁边的文字与代码。

所有教学图片均在 `images/`，使用 Matplotlib 生成，源码见 `tools/draw_part02.py`。
