## 6.0 谱系：三种基本范式

脚本：`script/06_architectures/00_architecture_taxonomy.py`

按【注意力可见性】划分，现代大模型只有三种：

| 范式 | 可见性 | 代表 | 擅长 |
|---|---|---|---|
| **Encoder-only** | 全双向 | BERT / RoBERTa | 分类、检索、抽取、embedding |
| Encoder-Decoder | 编码器双向 + 解码器因果 + 交叉 | T5 / BART / Whisper | 翻译、摘要、语音 |
| **Decoder-only** | 仅因果 | GPT / Llama / Qwen / Mistral | 开放生成、对话、推理 |

时间线：2017 Transformer → 2018 BERT/GPT-1 → 2019 T5/GPT-2 → 2020 GPT-3（涌现 + ICL）
→ 2022 ChatGPT（RLHF）→ 2023 Llama/GPT-4/Mistral → 2024 MoE + 长上下文成为标配
→ 2024+ 混合架构（注意力 + SSM）。

参数量速算：`L × (4d² + 3·d·d_ff) + vocab·d`

## 6.1 Encoder-only：BERT

```python
import torch.nn as nn

class BertBlock(nn.Module):
    def __init__(self, d_model, heads):
        super().__init__()
        self.ln1  = nn.LayerNorm(d_model)
        self.attn = nn.MultiheadAttention(d_model, heads, batch_first=True, dropout=0.0)
        self.ln2  = nn.LayerNorm(d_model)
        self.ff   = nn.Sequential(nn.Linear(d_model, 4*d_model), nn.GELU(),
                                  nn.Linear(4*d_model, d_model))

    def forward(self, x, need_weights=False):
        h = self.ln1(x)
        # 注意：这里【没有】因果掩码 → 每个位置都能看到整句（双向）
        o, w = self.attn(h, h, h, need_weights=True, average_attn_weights=False)
        x = x + o
        x = x + self.ff(self.ln2(x))
        return (x, w) if need_weights else x
```


## 6.2 Encoder-Decoder：T5 / BART

```python
import torch.nn as nn

class RMSNorm(nn.Module):                       # T5 是最早用 RMSNorm 的模型
    def __init__(self, d, eps=1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(d))
        self.eps = eps
    def forward(self, x):
        rms = torch.sqrt(torch.mean(x * x, dim=-1, keepdim=True) + self.eps)
        return x / rms * self.weight

def relative_position_bucket(rel_pos, bidirectional=True, num_buckets=32, max_distance=128):
    """近处每 1 个位置一个桶（精确），远处用对数分桶（共享参数，可外推）。"""
    ret = 0
    if bidirectional:
        num_buckets //= 2
        ret += (rel_pos > 0).long() * num_buckets
        n = torch.abs(rel_pos)
    else:
        n = torch.max(-rel_pos, torch.zeros_like(rel_pos))
    max_exact = num_buckets // 2
    is_small = n < max_exact
    large = max_exact + (torch.log(n.float() / max_exact)
                         / np.log(max_distance / max_exact) * (num_buckets - max_exact)).long()
    return ret + torch.where(is_small, n, torch.min(large, torch.full_like(large, num_buckets - 1)))
```

T5 的注意力有两个"反常识"细节：

```python

if self.has_relative_bias:
    ctx    = torch.arange(Tq)[:, None] - torch.arange(Tk)[None, :]
    bias   = self.rel_bias(relative_position_bucket(ctx)).permute(2, 0, 1)
    scores = scores + bias                      # ← 位置信息从这里进来
```

脚本：`script/06_architectures/02_encoder_decoder_t5.py`

T5 口号：**Everything is Text-to-Text**

```
翻译： "translate English to German: That is good." → "Das ist gut."
分类： "cola sentence: The course is jumping well." → "acceptable"
```

与原版 Transformer 的 4 个差异：

| 组件 | T5 的做法 |
|---|---|
| 归一化 | **RMSNorm**（最早使用它） |
| 位置 | **相对位置偏置**（分桶：近处精确、远处对数分桶），不用位置编码 |
| Linear | **全部不带 bias** |
| 预训练 | **Span Corruption**（挖掉一段，用哨兵 token 标记后还原） |

Span Corruption 比 MLM 好的原因：预测的是"一段话"而不是"一个词" → 信号更密集、更接近生成。

现状：通用 LLM 已转向 decoder-only，但 encoder-decoder 在**语音（Whisper）、翻译（NLLB）、多模态**上仍是首选。

## 6.3 Decoder-only：GPT 家族

```python
import torch, torch.nn as nn

class GPTBlock(nn.Module):
    """GPT-2 风格：LayerNorm 前置 + 带 bias 的 Linear + GELU。"""
    def __init__(self, d_model, heads, d_ff=None, dropout=0.1):
        super().__init__()
        d_ff = d_ff or 4 * d_model
        self.ln1  = nn.LayerNorm(d_model)
        self.attn = nn.MultiheadAttention(d_model, heads, dropout=dropout, batch_first=True)
        self.ln2  = nn.LayerNorm(d_model)
        self.ff   = nn.Sequential(nn.Linear(d_model, d_ff), nn.GELU(), nn.Dropout(dropout),
                                  nn.Linear(d_ff, d_model))
        self.drop = nn.Dropout(dropout)

    def forward(self, x):
        T = x.shape[1]
        mask = torch.ones(T, T, dtype=torch.bool, device=x.device).tril()   # 因果掩码
        h = self.ln1(x)
        x = x + self.drop(self.attn(h, h, h, attn_mask=mask)[0])
        x = x + self.ff(self.ln2(x))
        return x

class TinyGPT(nn.Module):
    def __init__(self, vocab, d_model, heads, layers, max_len=1024, tie=True):
        super().__init__()
        self.tok = nn.Embedding(vocab, d_model)
        self.pos = nn.Embedding(max_len, d_model)
        self.blocks = nn.ModuleList([GPTBlock(d_model, heads) for _ in range(layers)])
        self.ln_f = nn.LayerNorm(d_model)
        self.head = nn.Linear(d_model, vocab, bias=False)
        if tie:
            self.head.weight = self.tok.weight      # ← 权重绑定
```

脚本：`script/06_architectures/03_decoder_only_gpt.py`

GPT-2 的结构细节：Pre-LN、GELU、可学习绝对位置、**权重绑定**（输出层复用 embedding）。

```
绑定能省 vocab×d 参数（GPT-2: 50257×768 ≈ 38.6M）
现代大模型通常【不绑定】，因为词表太大（128k），绑定会干扰 embedding 的学习
```

**为什么 decoder-only 赢了**：

1. 目标统一（预测下一个 token）→ 天然适配"预训练 → 一切任务"
2. 规模化友好：结构简单、并行度高、工程优化收益最大
3. 涌现能力：上下文学习、思维链、代码
4. 工程惯性：整个推理生态都围绕它优化

代价：长输入时 prefill 成本高；做 embedding 时要特殊设计。

## 6.4 现代 Decoder-only 的"标准件"：Llama 家族

脚本：`script/06_architectures/04_llama_family.py`

从 GPT-2 到 Llama 只改了 5 件事，但每一件都被沿用至今：

| 组件 | GPT-2 | Llama-3 | 为什么改 |
|---|---|---|---|
| 归一化 | LayerNorm | **RMSNorm** | 更快、更稳、参数更少 |
| 位置 | 绝对位置 Emb | **RoPE (θ=500000)** | 相对位置 + 可外推 |
| FFN 激活 | GELU | **SwiGLU (8d/3)** | 同参数下效果更好 |
| 注意力 | MHA | **GQA (8 KV 头)** | KV Cache 省 4~8 倍 |
| Linear bias | 有 | **无** | 少一次访存 |

Llama 五件套的完整实现（每个都只有几行）：

```python
import torch, torch.nn as nn, torch.nn.functional as F

# ① RMSNorm：不做 re-centering（减均值），只做 re-scaling
class RMSNorm(nn.Module):
    def __init__(self, d, eps=1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(d))       # 只有 d 个参数（LayerNorm 是 2d）
        self.eps = eps
    def forward(self, x):
        return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps) * self.weight

# ② SwiGLU FFN：三个矩阵，多出来的那个用于"门控"
class SwiGLUFFN(nn.Module):
    def __init__(self, d_model, multiple_of=256):
        super().__init__()
        d_ff = int(multiple_of * ((int(8 * d_model / 3) + multiple_of - 1) // multiple_of))
        self.w1 = nn.Linear(d_model, d_ff, bias=False)   # gate
        self.w2 = nn.Linear(d_model, d_ff, bias=False)   # up
        self.w3 = nn.Linear(d_ff, d_model, bias=False)   # down
    def forward(self, x):
        return self.w3(F.silu(self.w1(x)) * self.w2(x))  # silu(x) = x·σ(x) = Swish

# ③ RoPE：相邻维度两两一组做旋转（这里是"前后半分组"的 Llama 写法）
def rope(x, freqs):                                      # x:(B,T,h,dh)
    half = x.shape[-1] // 2
    x1, x2 = x[..., :half], x[..., half:]
    cos, sin = torch.cos(freqs), torch.sin(freqs)
    return torch.cat([x1 * cos - x2 * sin, x2 * cos + x1 * sin], dim=-1)

# ④ GQA：多个 Q 头共享一组 K/V（实现上用 expand 而不是真的复制）
def repeat_kv(x, n_rep):
    if n_rep == 1:
        return x
    B, H, T, D = x.shape
    return x[:, :, None].expand(B, H, n_rep, T, D).reshape(B, H * n_rep, T, D)

# ⑤ 组装：Pre-LN + 残差，所有 Linear 都不带 bias
class LlamaBlock(nn.Module):
    def __init__(self, d_model, n_heads, n_kv_heads):
        super().__init__()
        self.ln1, self.ln2 = RMSNorm(d_model), RMSNorm(d_model)
        self.attn = GroupedQueryAttention(d_model, n_heads, n_kv_heads)
        self.ff = SwiGLUFFN(d_model)
    def forward(self, x):
        x = x + self.attn(self.ln1(x))
        x = x + self.ff(self.ln2(x))
        return x
```

## 6.5 MoE：用稀疏激活把模型"变大"而不变慢

脚本：`script/06_architectures/05_moe.py`

```
y = Σ_{i ∈ TopK(g(x))} g_i(x) · E_i(x)
总参数 = N × 单专家；激活参数 = k × 单专家
```

Mixtral-8×7B：8 个 7B 专家选 2 → 47B 总参数 / 13B 激活参数。

### 专家塌缩与负载均衡

```python
import torch, torch.nn as nn, torch.nn.functional as F

class MoELayer(nn.Module):
    def __init__(self, d_model, d_ff, num_experts=4, top_k=2):
        super().__init__()
        self.num_experts, self.top_k = num_experts, top_k
        self.experts = nn.ModuleList([Expert(d_model, d_ff) for _ in range(num_experts)])
        self.gate = nn.Linear(d_model, num_experts, bias=False)

    def forward(self, x, return_aux=False):
        B, T, d = x.shape
        xf = x.reshape(-1, d)                                     # (N, d)
        probs = torch.softmax(self.gate(xf), dim=-1)               # (N, E)
        topk_p, topk_idx = torch.topk(probs, self.top_k, dim=-1)
        topk_p = topk_p / topk_p.sum(-1, keepdim=True)

        y = torch.zeros_like(xf)
        for e in range(self.num_experts):                          # 按专家分组处理
            mask = (topk_idx == e).any(dim=-1)
            if mask.any():
                w = ((topk_idx == e) * topk_p).sum(-1, keepdim=True)[mask]
                y[mask] += w * self.experts[e](xf[mask])

        if not return_aux:
            return y.reshape(B, T, d)

        # ---- Switch Transformer 的负载均衡损失 ----
        one_hot = F.one_hot(topk_idx, self.num_experts).float()    # (N, k, E)
        f = one_hot.sum(dim=(0, 1)) / (xf.shape[0] * self.top_k)   # 实际分配比例（不可导）
        P = probs.mean(dim=0)                                      # 路由概率均值（可导）
        aux = self.num_experts * (f * P).sum()                     # 均匀分布时取最小值 1
        return y.reshape(B, T, d), aux
```

训练时的用法（辅助损失权重是关键超参）：

```python
h, aux, f = moe(x, return_aux=True)
loss = task_loss + 0.002 * aux          # 太大 → 专家变均匀不分化；太小 → 塌缩到 1 个专家
```

真实实现里 `for e in range(...)` 要换成 `cumsum + 稀疏 dispatch`，
否则每个 step 都要把**所有**专家跑一遍，稀疏性就白费了。

```
L_aux = E · Σ_i f_i · P_i
f_i = 实际分配比例（不可导，one-hot 统计）
P_i = 路由概率均值（可导）
均匀分布时取最小值 1
```

脚本在"两个领域有不同映射规则"的合成数据上训练后：

```
领域 A（正弦）   的 token 专家分布: [0.227 0.134 0.408 0.231]
领域 B（绝对值） 的 token 专家分布: [0.273 0.364 0.095 0.268]
```

→ 路由真的学到了有意义的划分（专家 2 偏好 A，专家 1 偏好 B）。

### 工程代价

1. **显存**：参数全部要装下（47B 需要 ~90GB），靠"专家并行"分散到多卡
2. **通信**：all-to-all 是主要开销
3. **负载均衡**：capacity factor + token 丢弃
4. **微调更易过拟合**
5. DeepSeek 创新：细粒度专家 + 共享专家 + **无辅助损失**（动态调整专家 bias）

## 6.6 SSM / Mamba：非注意力路线

```python
import torch
import torch.nn.functional as F

def discretize(A, B, delta):
    """零阶保持（ZOH）；Mamba 实际用的是一阶近似 B̄ ≈ Δ·B。"""
    return torch.exp(delta * A), delta * B

def ssm_recurrent(x, A, B, C, delta):                 # 推理用：O(1) 状态
    h = torch.zeros_like(A)
    ys = []
    for t in range(x.shape[0]):
        A_bar, B_bar = discretize(A, B, delta[t])
        h = A_bar * h + B_bar * x[t]                  # h_t = Ā·h_{t−1} + B̄·x_t
        ys.append((C * h).sum())
    return torch.stack(ys)

def ssm_convolution(x, A, B, C, delta):               # 训练用：一次卷积（可用 FFT）
    T = x.shape[0]
    A_bar, B_bar = discretize(A, B, delta[0])
    K = torch.stack([(C * (A_bar ** k) * B_bar).sum() for k in range(T)])
    return F.conv1d(x.view(1, 1, T), K.view(1, 1, T).flip(-1), padding=T - 1)[0, 0, :T]
```

脚本验证两种形式等价：

Mamba 的选择性扫描（串行版本，便于理解）：

```python
def selective_scan(x, A, B_fn, C_fn, delta_fn):
    h = torch.zeros_like(A)
    ys = []
    for t in range(x.shape[0]):
        xt = x[t]
        delta_t = F.softplus(delta_fn(xt))             # Δ 必须为正
        Bt, Ct = B_fn(xt), C_fn(xt)
        h = torch.exp(delta_t * A) * h + delta_t * Bt * xt
        ys.append((Ct * h).sum())
    return torch.stack(ys)
```

线性注意力与 SSM 的桥梁（数值验证）：

```python
lhs = (Q @ K.T) @ V        # 先算 T×T
rhs = Q @ (K.T @ V)        # 先算 d×d → O(T·d²)
# [OK] (QKᵀ)V vs Q(KᵀV)（无 softmax 时等价）: 最大绝对误差 = 1.526e-05
```

脚本：`script/06_architectures/06_mamba_ssm.py`

```
连续： h'(t) = A·h(t) + B·x(t),  y(t) = C·h(t)
离散： h_t = Ā·h_{t−1} + B̄·x_t,  y_t = C·h_t
```

**LTI 系统（S4）的美妙性质**：整个序列可以写成一次卷积 → 训练用 FFT 超快，推理用递归 O(1)。

**Mamba 的选择性**：Δ / B / C 依赖输入 → 不能卷积，改用**并行扫描（associative scan）**

```
把 (a, b) 定义成仿射变换 h ← a·h + b
结合律： (a₁,b₁) ⊗ (a₂,b₂) = (a₂a₁, a₂b₁ + b₂)    → 可像前缀和一样并行
```

复杂度对比：

```
T=16384 : 注意力 34G FLOPs   SSM 0.03G   （差 ~1000×）
T=262144: 注意力 8800G        SSM 0.5G
```

**线性注意力桥梁**：去掉 softmax 后 `(QKᵀ)V = Q(KᵀV)` → O(T·d²)。
Mamba-2 证明线性注意力与 SSM 是数学上的**对偶**（SSD），可用同一套 matmul 单元实现。

现实结论（2024~2025）：纯 SSM 在长文检索上仍弱于注意力 → 主流是**混合架构**（Jamba / Samba）。

## 6.7 注意力变体大乱斗

MLA 的极简实现（只缓存低秩潜向量 `c`）：

```python
class MLAAttention(nn.Module):
    def __init__(self, d_model, n_heads, d_c=64):
        super().__init__()
        self.h, self.dh = n_heads, d_model // n_heads
        self.d_c = d_c
        self.w_dkv = nn.Linear(d_model, d_c, bias=False)             # 下投影（压缩）
        self.w_uk  = nn.Linear(d_c, n_heads * self.dh, bias=False)   # 上投影 → K
        self.w_uv  = nn.Linear(d_c, n_heads * self.dh, bias=False)   # 上投影 → V
        self.w_q   = nn.Linear(d_model, n_heads * self.dh, bias=False)
        self.w_o   = nn.Linear(n_heads * self.dh, d_model, bias=False)

    def forward(self, x, is_causal=True):
        B, T, _ = x.shape
        c = self.w_dkv(x)                       # ← 只有这个进 KV Cache
        k = self.w_uk(c).view(B, T, self.h, self.dh).transpose(1, 2)
        v = self.w_uv(c).view(B, T, self.h, self.dh).transpose(1, 2)
        q = self.w_q(x).view(B, T, self.h, self.dh).transpose(1, 2)
        scores = (q @ k.transpose(-2, -1)) / (self.dh ** 0.5)
        if is_causal:
            scores = scores.masked_fill(~torch.ones(T, T, dtype=torch.bool).tril(), float("-inf"))
        out = (torch.softmax(scores, -1) @ v).transpose(1, 2).reshape(B, T, -1)
        return self.w_o(out), c
```

滑动窗口掩码（两行）：

```python
i = np.arange(T)[:, None]; j = np.arange(T)[None, :]
mask = (np.abs(i - j) <= W) & (j <= i)          # 只看左边 W 个
```

ALiBi（不加位置编码，直接在分数上减距离惩罚）：

```python
def alibi_bias(T, n_heads):
    slopes = 2 ** (-8 * np.arange(1, n_heads + 1) / n_heads)   # 每个头一个斜率
    dist = np.abs(np.arange(T)[:, None] - np.arange(T)[None, :])
    return -slopes[:, None, None] * dist[None]                  # (h, T, T)
```

脚本：`script/06_architectures/07_attention_variants.py`

| 变体 | 每 token KV | 相对 MHA | 代表 |
|---|---|---|---|
| MHA (32 KV) | 131 KB | 1.00 | 早期模型 |
| GQA (8 KV) | 32 KB | 0.25 | Llama-3 / Mistral |
| GQA (4 KV) | 16 KB | 0.13 | Qwen2.5 |
| MQA (1 KV) | 4 KB | 0.03 | 端侧小模型 |
| **MLA** | 1.1 KB | **0.0086** | DeepSeek-V2/V3 |

**MLA（Multi-head Latent Attention）**：

```
c_t = W_DKV · h_t            只缓存这个低秩潜向量（如 512 维）
k_t = W_UK · c_t  (+ RoPE 分量)
v_t = W_UV · c_t
推理时 W_UK / W_UV 可吸收进 W_Q / W_O → 连解压缩都省了
```

**滑动窗口**（Mistral：W=4096，32 层 → 理论感受野 131k）
**ALiBi**：不加位置编码，直接在分数上减 `slope_h · |i−j|`，外推极好、零参数。

选择建议：通用默认 GQA；长上下文/端侧考虑 MQA 或 MLA；从零训练就直接用 GQA。

## 6.8 多模态：ViT / CLIP / LLaVA

ViT 的 patch embedding（一行 Conv2d）：

```python
class PatchEmbedding(nn.Module):
    def __init__(self, img_size=32, patch_size=8, in_ch=1, d_model=64):
        super().__init__()
        self.num_patches = (img_size // patch_size) ** 2
        self.proj = nn.Conv2d(in_ch, d_model, kernel_size=patch_size, stride=patch_size)

    def forward(self, x):
        x = self.proj(x)                          # (B, d, H/P, W/P)
        return x.flatten(2).transpose(1, 2)       # (B, num_patches, d) ← 图像变成了 token 序列

class ViT(nn.Module):
    def forward(self, img):
        x = self.patch(img)
        x = torch.cat([self.cls.expand(img.shape[0], -1, -1), x], dim=1) + self.pos
        return self.head(self.encoder(x)[:, 0])   # 用 [CLS] token 做分类
```

CLIP 的对比损失（对称 InfoNCE，10 行）：

```python
def clip_loss(img_feat, txt_feat, temperature=0.07):
    img_feat = F.normalize(img_feat, dim=-1)
    txt_feat = F.normalize(txt_feat, dim=-1)
    logits = img_feat @ txt_feat.T / temperature          # (N, N)
    labels = torch.arange(img_feat.shape[0], device=img_feat.device)
    return 0.5 * (F.cross_entropy(logits, labels) + F.cross_entropy(logits.T, labels))

def retrieve_acc(img_enc, txt_enc, imgs, txts, labels):
    with torch.no_grad():
        sim = F.normalize(img_enc(imgs), -1) @ F.normalize(txt_enc(txts), -1).T
        pred = sim.argmax(1)
    return (labels[pred] == labels).float().mean().item()    # 按【类别】判对错，不能比索引
```

混合精度的最小实现（PyTorch 的 autocast + GradScaler）：

```python
scaler = torch.amp.GradScaler("cuda")            # fp16 需要；bf16 可以不用
for x, y in loader:
    opt.zero_grad()
    with torch.amp.autocast("cuda", dtype=torch.bfloat16):     # 前向用 bf16
        loss = F.cross_entropy(model(x), y)
    scaler.scale(loss).backward()                # 放大 loss 防止梯度下溢（fp16 场景）
    scaler.unscale_(opt)                         # 反缩放后再裁剪，否则阈值不对
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    scaler.step(opt)
    scaler.update()
```

激活重计算的开关（一行）：

```python
out = torch.utils.checkpoint.checkpoint(layer, x)   # 前向不存中间激活，反向时重算
```

脚本：`script/06_architectures/09_training_stack.py`

| 策略 | 切什么 | 通信 | 适用 |
|---|---|---|---|
| DP | 数据 | 梯度 all-reduce | 模型能装进单卡 |
| ZeRO-1/2/3 | 优化器状态 / 梯度 / 参数 | reduce-scatter / all-gather | 装不下 |
| TP | 单层的矩阵（列/行切） | all-reduce（每层 2 次） | 机内（需 NVLink） |
| PP | 层 | 只传边界激活 | 跨机 |
| SP | 序列维度 | all-gather | 长上下文 + TP |
| EP | MoE 专家 | all-to-all | MoE |

混合精度：**bf16 的指数位与 fp32 相同**（动态范围一致，不易溢出/下溢），
尾数位只有 7 位（精度低）→ 必须保留 fp32 主权重做累加。

激活重计算：多算一次前向（+30% 时间）换 5~10× 激活显存，训练必开。

训练不稳定的常见原因：坏数据导致 loss 尖峰、bf16 下溢、TP 漏了 all-reduce、
位置编码越界、初始化过大。
