## A. 数学与优化

| 符号 / 术语 | 含义 |
|---|---|
| θ / W / b | 参数（权重、偏置） |
| ŷ | 模型预测值 |
| ℓ(ŷ, y) | 单个样本的损失 |
| L(θ) | 全体样本的平均损失 |
| ∇θL | 损失对参数的梯度 |
| lr / η | 学习率 |
| batch / epoch / step | 一批 / 一轮 / 一次参数更新 |

```
梯度下降        θ ← θ − lr·∇L
Momentum        v ← μv − lr·g ; θ ← θ + v
Adam            m ← β₁m+(1−β₁)g ; v ← β₂v+(1−β₂)g² ; θ ← θ − lr·m̂/(√v̂+ε)
MSE             mean((ŷ − y)²)
交叉熵(BCE)     −[y·log p + (1−y)·log(1−p)]
交叉熵(多类)    −log p[正确类别]          （等价于 log softmax + NLL）
Perplexity      exp(交叉熵)
```

**常用激活与导数**

| 函数 | 表达式 | 导数 |
|---|---|---|
| sigmoid | `1/(1+e^-x)` | `a(1−a)` |
| tanh | `tanh(x)` | `1−a²` |
| ReLU | `max(0,x)` | `x>0 ? 1 : 0` |
| GELU | `x·Φ(x) ≈ 0.5x(1+tanh(0.7979(x+0.044715x³)))` | — |
| Swish/SiLU | `x·σ(x)` | — |
| softmax | `e^{xᵢ}/Σe^{xⱼ}` | `diag(s) − ssᵀ` |

## B. 神经网络层

| 层 | 前向 | 参数量 | 备注 |
|---|---|---|---|
| Linear | `y = xWᵀ + b` | `d_in·d_out + d_out` | LLM 参数的主体 |
| Conv2d | 见下 | `C_out·C_in·K² + C_out` | 与输入分辨率无关 |
| LayerNorm | `(x−μ)/σ·γ + β` | `2d` | |
| RMSNorm | `x/√(mean(x²))·γ` | `d` | Llama 系标配 |
| Embedding | 查表 | `vocab·d` | |
| MultiHeadAttn | 见下 | `4d²`（GQA 更少） | |
| FFN (GELU) | `W₂·GELU(W₁x)` | `8d²` | d_ff = 4d |
| FFN (SwiGLU) | `W₃(Swish(W₁x)⊙W₂x)` | `3·d·(8d/3) ≈ 8d²` | Llama 系标配 |

```
卷积输出尺寸  OH = (H + 2·pad − dilation·(K−1) − 1)/stride + 1
感受野递推    RF_l = RF_{l−1} + (K_l − 1)·Π_{i<l} stride_i
```

## C. 注意力与 Transformer

```
Attention(Q,K,V) = softmax(QKᵀ/√d_k)·V
MultiHead        = Concat(head₁..head_h)·W_O,  head_i = Attn(XW_Qⁱ, XW_Kⁱ, XW_Vⁱ)
RoPE             ⟨R_m q, R_n k⟩ = ⟨R_0 q, R_{n−m} k⟩
SwiGLU           FFN(x) = (Swish(xW₁) ⊙ xW₂)W₃
```

| 缩写 | 全称 | 含义 |
|---|---|---|
| MHA | Multi-Head Attention | Q 头数 = KV 头数 |
| MQA | Multi-Query Attention | 所有 Q 共享 1 个 KV 头 |
| GQA | Grouped-Query Attention | 每组 Q 共享 1 个 KV 头（Llama-3） |
| MLA | Multi-head Latent Attention | 缓存低秩潜向量（DeepSeek） |
| RoPE | Rotary Position Embedding | 旋转位置编码 |
| ALiBi | Attention with Linear Biases | 分数上减距离惩罚 |
| PE | Positional Encoding | 位置编码 |
| FFN / MLP | Feed-Forward Network | 逐位置前馈网络 |
| LN / RMSN | LayerNorm / RMSNorm | 归一化 |

**参数量速算**

```
Transformer 参数 ≈ L × (4d² + 3·d·d_ff) + vocab·d
Llama 风格（SwiGLU, d_ff=8d/3）≈ L × 12d² + 2·vocab·d
Llama-7B: 32 × 12 × 4096² ≈ 6.4B ✔
```

## D. LLM 工程

```
KV Cache        = L × 2 × batch × seq × kv_heads × head_dim × bytes
训练显存/参数    ≈ 16 字节（bf16 权重+梯度 + fp32 主权重 + Adam m/v）
训练 FLOPs      ≈ 6·N·D
推理 FLOPs      ≈ 2·N·D（只有前向）
算术强度 AI     = FLOPs / Bytes
Roofline        = min(峰值算力, 峰值带宽 × AI)
ridge point     = 峰值算力 / 峰值带宽 ≈ 12.5 FLOP/Byte（A100 fp32）
```

| 术语 | 含义 |
|---|---|
| Prefill | 处理输入 prompt（一次算完，计算密集） |
| Decode | 逐个生成 token（访存密集） |
| TTFT | 首 token 延迟 |
| TPOT | 每个输出 token 的时间 |
| KV Cache | 缓存已算过的 K/V，避免重复计算 |
| PagedAttention | KV Cache 分页管理（vLLM） |
| Continuous Batching | 请求级动态进出 batch |
| Speculative Decoding | 小模型起草 + 大模型并行验证 |
| ICL | In-Context Learning（上下文学习） |
| CoT | Chain-of-Thought（思维链） |
| RLHF / DPO | 人类反馈强化学习 / 直接偏好优化 |
| PEFT / LoRA | 参数高效微调 / 低秩适配 |
| QLoRA | 4-bit 底座 + LoRA 适配器 |
| MoE | Mixture of Experts（稀疏激活） |
| SSM / Mamba | 状态空间模型 |

**量化速查**

```
对称 absmax      s = max|W|/127 ; W_q = round(W/s)
W8A8            权重与激活都量化 → 可用 INT8 TensorCore
W4A16           只量化权重 → 省显存带宽，decode 加速明显
NF4 (QLoRA)     4-bit，16 个级别按正态分布密度布置
分组量化        group_size=32/64/128，几乎无损，开销可忽略
```

## E. CUDA / GPU

```
全局索引   i = blockIdx.x * blockDim.x + threadIdx.x
启动       kernel<<<grid, block, shared_bytes, stream>>>(args)
算力       A100=sm_80  V100=sm_70  RTX3090=sm_86  RTX4090=sm_89  H100=sm_90
内存层次   寄存器 > Shared/L1 > L2 > HBM
```

| 术语 | 含义 |
|---|---|
| Warp | 32 个线程，锁步执行同一条指令 |
| CTA / Block | 协作线程块，调度到一个 SM |
| Occupancy | 活跃 warp / SM 最大 warp |
| Coalescing | warp 内连续访问合并成少数内存事务 |
| Bank Conflict | 多线程访问同一 shared bank → 串行 |
| Divergence | warp 内分支不一致 → 两个分支串行执行 |
| Spill | 寄存器不够，溢出到 local memory（很慢） |
| TensorCore | 专用矩阵乘单元（fp16/bf16/fp8/tf32） |
| cp.async / TMA | 全局→共享的异步拷贝（Hopper 上更强） |
| CUDA Graph | 把一串 kernel 录成图，消除启动开销 |

**常用命令**

```bash
nvcc -O3 -arch=sm_80 -Xptxas -v foo.cu -o foo -lcublas   # -Xptxas -v 看寄存器占用
nsys profile -o rep ./foo                                 # 时间线
ncu --set full ./foo                                      # kernel 详解
compute-sanitizer ./foo                                   # 越界/竞态
export TORCH_CUDA_ARCH_LIST="8.6"                         # 解决算力不匹配
TRITON_INTERPRET=1 python3 foo.py                         # 调试 Triton
```

## G. 容易记混的几组概念

| 易混 | 区别 |
|---|---|
| Pre-LN vs Post-LN | 归一化在子层**前**还是**后**；现代用 Pre-LN |
| 自注意力 vs 交叉注意力 | K/V 来自自身还是另一个序列 |
| Encoder-only vs Decoder-only | 双向可见 vs 仅因果可见 |
| 静态批处理 vs 连续批处理 | 等整批跑完 vs 每个 step 动态进出 |
| Prefill vs Decode | 计算密集 vs 访存密集 |
| 量化 vs 剪枝 vs 蒸馏 | 降位宽 / 删结构 / 用小模型学大模型 |
| LoRA vs 全量微调 | 低秩增量（可合并） / 更新全部参数 |
| GQA vs MQA vs MLA | 共享 KV 的程度不同；MLA 是低秩压缩 |
| FlashAttention vs 稀疏注意力 | 精确的分块实现 / 只算部分位置（近似） |
| compute-bound vs memory-bound | 看 Roofline：AI 大于还是小于 ridge point |
