## 1.1 机器学习的统一范式

所有监督学习都在解同一个优化问题：

```
给定数据 (x₁,y₁), ..., (xₙ,yₙ)，找一组参数 θ，使得  L(θ) = (1/n)Σ ℓ(f(xᵢ;θ), yᵢ)  最小
```

四个要素：

| 要素 | 含义 | 本章例子 |
|---|---|---|
| 模型 f | 参数化的函数 | `ŷ = Xw + b`（线性回归）、`MLP` |
| 损失 ℓ | 衡量"预测有多离谱" | MSE、交叉熵 |
| 优化器 | 怎么更新 θ | SGD / Momentum / Adam |
| 正则化 | 防止"背答案" | L2、Dropout、早停 |

而求解方式 99% 都是同一个循环（第 1 个脚本就把它写了 4 遍）：

```python
for step in range(steps):
    pred = model(x)          # ① 前向
    loss = loss_fn(pred, y)  # ② 损失
    grad = backward(...)     # ③ 反向（链式法则）
    θ -= lr * grad           # ④ 更新
```

> 📌 深度学习和它**唯一**的区别是：③ 的梯度是在一张巨大的计算图上用链式法则自动算出来的。

## 1.2 梯度下降的三个层次

脚本：`script/01_ml_basics/01_gradient_descent.py`

### 最朴素的形式

```python
import numpy as np

A = np.array([[3.0, 1.0], [1.0, 2.0]])        # 目标：f(w) = wᵀAw，一个"碗"

def f(w):    return float(w @ A @ w)
def grad(w): return (A + A.T) @ w              # ∇f = (A + Aᵀ)w

w = np.array([3.0, -4.0])
for step in range(200):
    w -= lr * grad(w)                          # ← 梯度下降的全部：沿梯度反方向走一小步
print(w)                                       # → 趋近 [0, 0]
```

`lr`（学习率）是最重要的超参数。脚本扫描 `lr ∈ [0.01, 0.8]` 后你会看到：
`lr=0.05` 平稳收敛，而 `lr=0.8` 时 loss 直接飙到 `1e111`（发散）。
判断依据很简单：**前几十步 loss 不降反升，就是 lr 太大**。

```python
w = w - lr * dL/dw
```

`lr`（学习率）是最重要的超参数：太大发散，太小收敛慢。脚本里扫描了 `lr ∈ [0.01, 0.8]`，
你会看到 `lr=0.8` 时 loss 直接飙到 `1e111`。

### Momentum：给梯度加"惯性"

```
v = μ·v − lr·g        (μ 通常 0.9)
w = w + v
```

解决"峡谷地形来回震荡"：垂直于谷底方向的梯度被相互抵消，沿谷底方向的分量不断累积。

### RMSProp / Adam：逐维度缩放学习率

完整实现（20 行，可直接抄）：

```python
def adam(grad_fn, w0, lr=0.05, steps=200, b1=0.9, b2=0.999, eps=1e-8):
    w = w0.copy()
    m = np.zeros_like(w)                       # 一阶动量（梯度的指数平均 = 方向）
    v = np.zeros_like(w)                       # 二阶动量（梯度平方的平均 = 每个维度的曲率）
    for t in range(1, steps + 1):
        g = grad_fn(w)
        m = b1 * m + (1 - b1) * g
        v = b2 * v + (1 - b2) * g * g
        mhat = m / (1 - b1 ** t)               # 偏差修正：前几步 m、v 偏小，必须补
        vhat = v / (1 - b2 ** t)
        w -= lr * mhat / (np.sqrt(vhat) + eps)
    return w
```

对照一下 Momentum（只有三行）：

```python
v = np.zeros_like(w)
for step in range(steps):
    v = mu * v - lr * grad(w)                  # 惯性：保留过去梯度的指数加权平均
    w += v
```

```
Adam:
  m = β₁·m + (1−β₁)·g                 一阶动量（方向）
  v = β₂·v + (1−β₂)·g²                二阶动量（每个维度各自的"曲率"）
  m̂ = m/(1−β₁ᵗ),  v̂ = v/(1−β₂ᵗ)      偏差修正（前几步 m,v 偏小）
  w = w − lr·m̂/(√v̂ + ε)
```

**为什么 LLM 都用 AdamW**：自适应学习率让"每个参数有自己的步长"，对稀疏梯度（embedding）
和尺度差异巨大的层特别友好；W 指 decoupled weight decay（权重衰减不经过动量）。

脚本输出示例（同一个碗形函数，200 步后到最优解的距离）：

```
GD       6.93e-13     Momentum  1.18e-04
RMSProp  2.48e-16     Adam      7.53e-05
```

## 1.3 线性回归：闭式解 vs 梯度下降

脚本：`script/01_ml_basics/02_linear_regression.py`

| | 闭式解 | 梯度下降 |
|---|---|---|
| 公式 | `w = (XᵀX)⁻¹Xᵀy` | 迭代 `w -= lr·(2/n)Xᵀ(ŷ−y)` |
| 复杂度 | O(d³) 求逆 + O(n·d²) | 每步 O(batch·d) |
| 适用 | d 小（几千以内） | d 巨大（LLM 有几十亿参数，只能用后者） |

**特征标准化是必需项，不是可选项**。脚本里把某一维放大到 100 量级后，
同样的学习率要么在该维度发散、要么在其他维度走不动 —— 这一点后面会以
`LayerNorm / RMSNorm` 的形式反复出现（它们就是"每一层都做一次动态标准化"）。

## 1.4 逻辑回归与交叉熵

完整训练代码（不含任何框架，30 行）：

```python
import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

def train_logreg(X, y, lr=0.5, steps=800):
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    for _ in range(steps):
        p = sigmoid(X @ w + b)                       # (n,)
        dz = (p - y) / n                             # ← BCE + sigmoid 的梯度就这么简单
        w -= lr * (X.T @ dz)                         # dW = Xᵀ · dz
        b -= lr * dz.sum()
        # 数值稳定版损失（log-sum-exp 技巧，避免 log(0)）
        loss = -np.mean(y * np.log(p + 1e-12) + (1 - y) * np.log(1 - p + 1e-12))
    return w, b
```

预测与评估：

```python
p = sigmoid(X @ w + b)
yhat = (p >= 0.5).astype(int)                        # 阈值就是决策边界
acc = (yhat == y).mean()
```

脚本：`script/01_ml_basics/03_logistic_regression.py`

```python
p = sigmoid(X @ w + b)                                    # sigmoid(z) = 1/(1+e^-z)
loss = -np.mean(y * np.log(p + 1e-12) + (1 - y) * np.log(1 - p + 1e-12))
dz   = (p - y) / n                                        # ← 极其简洁，因为 σ' 被抵消了
```

> 这个简洁不是巧合：**sigmoid + BCE 是刻意配对的**，就像 `softmax + CE` 一样。
> 如果换成 MSE，梯度里会多一个 `σ'(z)` 因子，预测极端错误时 `σ'≈0` → 梯度消失 → 学不动。
> 脚本里做了对照实验：同样 800 步，交叉熵准确率 ~0.99，MSE 明显更低。

**记住这个视角**：LLM 的最后一层就是"5 万分类的逻辑回归"（vocab 上的 softmax + 交叉熵）。

## 1.5 反向传播：本章最重要的一节

脚本：`script/01_ml_basics/04_mlp_numpy.py`

两层 MLP：`x → Linear → tanh → Linear → tanh → Linear → sigmoid`

### 通用模式（请背下来）

```
前向时：缓存每一层的输入 x 和激活输出 a
反向时：从后往前
    dW   = xᵀ · dout          （形状：fan_in × fan_out）
    dx   = dout · Wᵀ
    中间乘上激活函数的导数：tanh' = 1 − a², sigmoid' = a(1−a)
```

**为什么激活导数只用激活值就能算**：这是前向必须缓存 `a` 的原因，也是显存开销的来源之一
（后面第 5 章的"激活重计算"就是在省这块显存）。

### 必做步骤：梯度检查

```python
def grad_check(f, w, i, eps=1e-6):
    """中心差分：误差 O(eps²)，比单侧差分精确一个量级。"""
    w[i] += eps;  f_plus  = f(w)
    w[i] -= 2*eps; f_minus = f(w)
    w[i] += eps
    return (f_plus - f_minus) / (2 * eps)

# 用法：拿它和你手写的解析梯度逐项比对
for i in range(w.size):
    num = grad_check(lambda ww: loss_fn(X, y, ww), w, i)
    print(f"  w[{i}]: 数值={num: .8e}  解析={analytic[i]: .8e}  差={abs(num-analytic[i]):.2e}")
```

脚本 `04_mlp_numpy.py` 的真实输出（全部权重都通过）：

```
[OK] dL/dW（全部权重）: 最大绝对误差 = 1.389e-10 (tol=1e-06)
```

> 写任何自定义反向传播（包括第 7 章的 CUDA 算子）**第一步永远是 grad check**。
> 常见错误 90% 是：转置写反、忘记累加（同一个张量被多处使用时梯度要相加）、漏了激活导数。

```python
def grad_check(f, w, i, eps=1e-6):
    w[i] += eps;  f_plus  = f(w)
    w[i] -= 2*eps; f_minus = f(w)
    w[i] += eps
    return (f_plus - f_minus) / (2 * eps)        # 中心差分，误差 O(eps²)

assert abs(grad_check(loss_fn, w, i) - analytic[i]) < 1e-6
```

脚本里用 `common_utils.grad_check` 验证了全部权重（见上面的真实输出）。

### 为什么必须有非线性

线性层叠起来还是线性：`W₂(W₁x) = (W₂W₁)x`。没有激活函数，再深也等价于一层。

## 1.6 决策树：不用微积分的另一条路

脚本：`script/01_ml_basics/05_decision_tree.py`

```text
Gini(p) = 1 − Σ pₖ²                        0 = 纯，二分类时 0.5 最杂
Gain    = impurity(父) − Σ (nᵢ/n)·impurity(子ᵢ)
```

递归三行：找最优 (特征, 阈值) 切分 → 切成两半 → 对两半递归。

| | 决策树 / GBDT | 神经网络 |
|---|---|---|
| 优势 | 可解释、不需标准化、天然非线性、混合类型特征 | 可微分 → 端到端；适合高维/稠密/序列/图像 |
| 劣势 | 不能外推、高维稀疏（文本）差 | 需要大量数据与算力 |
| 现状 | **表格数据的王者**（XGBoost/LightGBM） | 文本/图像/语音的绝对主流 |

有趣的连接：LLM 里的 **MoE 路由**（第 6 章）本质上就是"可微分的软决策树"。

## 1.7 正则化：怎么诚实地报告"模型有多好"

脚本：`script/01_ml_basics/06_metrics_cv.py`、`07_regularization.py`

### 指标

手写 AUC（用 rank 的等价公式，O(n log n)）：

```python
def roc_auc(y_true, score):
    """AUC = 随机抽一个正样本、一个负样本，正样本得分更高的概率。"""
    order = np.argsort(score)
    ranks = np.empty(len(score), dtype=np.float64)
    ranks[order] = np.arange(1, len(score) + 1)          # 并列时严格说要取平均秩
    n_pos, n_neg = y_true.sum(), (1 - y_true).sum()
    return (ranks[y_true == 1].sum() - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)

def f1_score(y, yhat):
    tp = ((y == 1) & (yhat == 1)).sum()
    fp = ((y == 0) & (yhat == 1)).sum()
    fn = ((y == 1) & (yhat == 0)).sum()
    p, r = tp / (tp + fp + 1e-12), tp / (tp + fn + 1e-12)
    return 2 * p * r / (p + r + 1e-12)
```

k 折交叉验证（别再只切一次训练/测试集了）：

```python
def kfold_indices(n, k=5, seed=0):
    idx = np.random.default_rng(seed).permutation(n)
    folds = np.array_split(idx, k)
    for i in range(k):
        valid = folds[i]
        train = np.concatenate([folds[j] for j in range(k) if j != i])
        yield train, valid                                # 每个 fold 都当一次验证集
```

- 类别不平衡时**准确率会骗人**（"全预测为 0"也有 90% 准确率）→ 看 **PR 曲线 / AUC / F1**
- `AUC`：ROC 曲线下面积，与阈值选择无关，是不平衡数据下的更好指标
- `perplexity ≈ exp(交叉熵)`：LLM 沿用了这个概念

### 四种武器

| 方法 | 做法 | 在 LLM 里的对应物 |
|---|---|---|
| L2 / 权重衰减 | `loss + λ·Σw²` | AdamW 的 `weight_decay` |
| L1 | `loss + λ·Σ|w|` | 稀疏化 / 剪枝的动机 |
| Dropout | 训练时随机置零（inverted dropout 推理时要放大 `1/(1-p)`） | 每个子层输出上 p≈0.1 |
| Early Stopping | 验证集上升就停 | 每隔 N 步存 checkpoint 再挑 |

脚本验证了 L1 会产生稀疏解（权重直接变 0），而 L2 只会让权重变小。

## 1.8 从 numpy 到 PyTorch

标准训练循环（后面所有章节都长这样，请直接背下来）：

```python
import torch, torch.nn as nn, torch.nn.functional as F

model = nn.Sequential(nn.Linear(2, 16), nn.Tanh(), nn.Linear(16, 1))
opt   = torch.optim.AdamW(model.parameters(), lr=1e-2, weight_decay=1e-4)

for step in range(2000):
    opt.zero_grad()                                            # ① 清空梯度（不清会累加！）
    logits = model(X).squeeze(-1)
    loss   = F.binary_cross_entropy_with_logits(logits, y)     # ② 前向 + 损失（含 log-sum-exp）
    loss.backward()                                            # ③ 反向：自动链式求导
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)    # ④ 梯度裁剪（防 loss 尖峰）
    opt.step()                                                 # ⑤ 更新
```


脚本：`script/01_ml_basics/08_torch_autograd_bridge.py`

PyTorch 只替你做了两件事：

1. **自动求导**：`requires_grad=True` 的 tensor 参与的所有运算被记进计算图，`backward()` 自动链式求导
2. **算子加速**：把 for 循环里的矩阵乘法换成高度优化的 GPU kernel（第 7 章你会自己写）

标准五步循环（后面所有章节都长这样）：

```python
opt.zero_grad()      # ① 清空上一步梯度（不清会累加！）
pred = model(x)      # ② 前向
loss = loss_fn(pred, y)
loss.backward()      # ③ 反向
opt.step()           # ④ 更新
```

脚本用同一个 MLP 做了对照：`手写梯度 vs autograd`，误差 `1e-16` 量级。

> ⚠️ 最常踩的坑：numpy 默认 `float64`，torch 模型参数默认 `float32`，混用会报 dtype 错误。
> 建张量时显式写 `dtype=torch.float32`。

## 1.9 速记卡

```
· 训练循环 = forward → loss → backward → step（+ zero_grad）
· 反向传播 = 从后往前反复用 dW = xᵀ·dout，中间乘激活导数
· 写完反向传播第一件事：grad check（有限差分）
· lr 最重要；Adam/AdamW 是默认选择；warmup + 余弦衰减标配
· 类别不平衡看 AUC/F1，别看 accuracy
· 标准化几乎总是必需的（LayerNorm/RMSNorm 是它的"动态版"）
· 非线性是深度的前提：没有激活函数，再深也等价于一层
```
